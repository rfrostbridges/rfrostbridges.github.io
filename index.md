# Apps by Robert Frost-Bridges

- [Keymode](keymode/), a vim-style text editor for iPhone (called Modus until 17 October 2026)
- [Inputrc](inputrc/), a keyboard-driven text editor for iPhone, worked with Ctrl and Meta keys
- [Diurnall](diurnall/), a journal for iPhone: a plain-text note for every day, with an Agenda, tasks and a calendar
